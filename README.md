# Basic Calculator

A simple browser calculator with a glossy Y2K-inspired look. It supports addition, subtraction, multiplication, division, decimals, and clearing the display.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Use the on-screen buttons to enter an expression and press `=` to calculate.

No build tools or dependencies are required.

## Built with

- HTML
- CSS
- JavaScript

# Базовый калькулятор

Простой калькулятор для браузера с глянцевым оформлением в стиле Y2K. Поддерживает сложение, вычитание, умножение, деление, десятичные числа и очистку экрана.

## Запуск

1. Скачайте или клонируйте этот репозиторий.
2. Откройте файл `index.html` в современном браузере.
3. Введите выражение кнопками на экране и нажмите `=`, чтобы получить результат.

Сборка и установка зависимостей не требуются.

## Использованные технологии

- HTML
- CSS
- JavaScript
